# Contributing

Keep SpaceJam small: desktop switching, clear permission status, and a simple
settings window. See [development notes](docs/DEVELOPMENT.md) for build and
validation instructions.

For a bug report, include your macOS version, SpaceJam version, duration,
number of ordinary desktops, and whether the issue happens with a keyboard
or a mouse shortcut. Do not include passwords, signing keys, or input logs.

When changing the gesture engine, retain its Apache-2.0 headers and upstream
notices. App interface and original project code use MIT. State which checks
you ran and distinguish event-format tests from real desktop-switching tests.
